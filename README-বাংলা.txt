আই টাচৃ লিংক — অফলাইন ইনস্টল প্যাকেজ

প্রকাশের জন্য এই ফোল্ডারের সব ফাইল একই ডিরেক্টরিতে HTTPS হোস্টিংয়ে আপলোড করুন। GitHub Pages/HTTPS ছাড়া PWA ইনস্টল হবে না।

ইনস্টল: প্রথমবার ইন্টারনেট চালু রেখে সাইট খুলুন। Android Chrome: Menu > Install app / Add to Home screen। Windows Chrome/Edge: Install icon অথবা Menu > Install page as app।

ডেটা: প্রতিটি ডিভাইসের হিসাব আলাদা Local Storage-এ থাকে; কোনো cloud sync নেই। Settings > Backup থেকে JSON ব্যাকআপ নিন এবং Restore দিয়ে ফিরিয়ে আনুন। ব্রাউজারের site data মুছলে হিসাব মুছে যেতে পারে।

রিপোর্ট: CSV ফাইল Excel-এ খোলা যায়; Print রিপোর্ট থেকে Save as PDF ব্যবহার করুন।
